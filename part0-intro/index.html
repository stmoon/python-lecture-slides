실습 환경과 진행 방식

실습 환경 확인 절차와 강의 진행 방식

$ python --version
Python 3.11.9

$ pip install numpy pandas matplotlib

$ python -c "import numpy, pandas, matplotlib"

버전 — 파이썬 3.10 이상 권장  ·  세 줄 모두 오류 없이 끝나면 준비 완료

진행 방식

  • 이론 — 슬라이드의 코드를 그 자리에서 실행하며 확인
  • 연습문제 — 파트별 3~9문제, 직접 채운 뒤 즉시 실행

  • 마무리 — 센서 로그 한 건을 적재부터 리포트까지 처리
